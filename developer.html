DEVELOPER PLATFORM

KINGBOT API

Versioned read-only account, broker, bot and execution data access for integrations. API keys are generated server-side and stored as hashes.

BASE

/api/developer/v1

AUTHENTICATION

X-API-Key: kb_live_...

SCOPES

profile:readaccount:readbots:readtrades:read

ENDPOINTS

GET /profile
GET /account
GET /bots
GET /trades

The developer API is intentionally read-only at this boundary. It cannot place trades, modify risk, disconnect brokers, or move customer funds.
