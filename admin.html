CONNECTIVITY POLICY

SECURE BROKER LAYER
Broker credentials remain encrypted server-side. The Admin page exposes only provider, account identifier, execution mode, enabled state and connection status. Disconnecting a user closes the current server-side connection; it does not delete the stored encrypted mapping.

AI ACCESS POLICY

DECISION SUPPORT
KINGBOT Intelligence is available to the verified administrator without a subscription. Customer AI access remains plan-gated; account-specific answers use server-generated broker/runtime/risk context and should not invent account values.

AUTHENTICATION

IDENTITY LAYER

SECRETS

PROTECTED
