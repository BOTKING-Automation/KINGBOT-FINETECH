# KINGBOT V12.4 — Regime-Aware Selective Cortex

## Objective

Test whether causal market-state context and a selective prediction architecture improve on V12.3. V12.3 produced one development-qualified specialist, but it failed the untouched final gate; HOLD recall was weak on that final candidate. V12.4 therefore tests whether the model can identify tradable conditions before predicting direction.

## Causal market-state context

V12.4 derives 18 OHLC-only features per candle: normalized 1/5/20-bar returns, ATR percentage and expansion, realized volatility, efficiency ratios, EMA spread, true-range expansion, directional persistence, choppiness, range position and five one-hot diagnostic states (neutral/transition, trend, range, volatility expansion and compression).

All indicators are trailing calculations on closed bars. The regime states are explicit heuristic labels, not true labels of institutional order flow, dealer inventory or future profitability. Multi-timeframe context is joined only after the source candle close. Missing history remains missing; it is never forward-filled from an unclosed candle.

## Predeclared challengers

1. single_head_full_cortex: the V12.3 three-class Transformer retrained on V12.4's enlarged causal feature/context tensors.
2. regime_selective_two_stage: a shared Transformer encoder with two heads:
   - actionability: SELL/BUY versus HOLD;
   - direction: SELL versus BUY, trained only on directional rows.

The actionability probability is temperature-calibrated and the abstention threshold is selected by actionability F1 on a chronological calibration subset within the outer training fold. A prediction below the selected threshold maps to HOLD; otherwise the direction head selects SELL or BUY. This is a research decision rule only.

## Calibration and leakage controls

Every outer fold uses a nested chronological split: the outer training portion is split 80/20 into a model-fit core and a calibration slice using the global temporal split with forward-label purging. Gradient updates use only the inner core. Temperature scaling and the actionability threshold use only the calibration slice. Neither calibration nor model fitting sees outer evaluation labels.

Development is 70%-85%; final is 85%-100% and stays untouched unless one candidate passes the development guard. The matched V9 reference is trained on the same inner core as the V12.4 challengers. Scaling is fitted on that same core only.

## Acceptance gates (unchanged)

- Balanced accuracy >= 0.36.
- Macro-F1 >= 0.34.
- At least 30 test samples.
- Nonzero SELL, HOLD and BUY recall.
- Development score delta >= -0.01 to qualify for final evaluation.
- Final selection-score improvement >= 0.005 versus matched V9, in addition to the absolute quality gates.

Regime breakdown, actionability precision/recall/F1, selected-trade coverage, directional accuracy among selected actionable rows, Brier score and expected calibration error are reported as diagnostics. They do not replace the unchanged acceptance gates.

## Data coverage

The workflow retains the V12.3 closed-history collection target of 3,000 bars per series. The market-data fetcher and ML bar normalizer both cap history at 3,000, so this experiment does not claim to extend that limit. Each feed's actual bar count and date range are retained in the artifact. Shorter higher-timeframe FX series, including the 363-bar 4h series observed in V12.3, must be treated as limited context coverage rather than full history.

## Research-only boundary

No production inference path, model registry, persisted weights, Render configuration, broker connection, customer account, secret, or live/demo order execution is changed. Even a successful classification gate would not prove profitability. Any later release discussion requires additional walk-forward and regime-separated windows, execution-aware spread/slippage/commission tests, drawdown analysis and shadow observation.
