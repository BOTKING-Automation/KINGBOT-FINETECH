## Risks to resolve in candidate research
1. The script is an indicator, not a Strategy Tester strategy. Its performance panel is not a cost-aware backtest.
2. Current trade-ledger performance does not model spread, commission, slippage, execution delay or financing.
3. R accounting assumes equal one-third allocations at TP1/TP2/TP3; confirm this matches the intended execution plan.
4. If SL and TP are both touched inside one chart bar, current tracking checks the stop first. This is conservative but needs lower-timeframe/tick validation.
5. Higher-timeframe `request.security(..., lookahead_off)` values can reflect a still-forming HTF candle in realtime. Confirm realtime-versus-reload consistency before using this bias as a hard signal gate.
6. Pivot drawings are plotted at their pivot bar only after right-side bars confirm. Distinguish pivot location from the later confirmation time.
7. The volume condition uses the chart feed's volume; for CFD gold, verify whether it is tick volume or exchange volume.
8. Existing order-block selection uses an extreme search from a swing-to-break range. Validate the definition before building the new SMC entry state machine around it.
9. Historical drawing retention is bounded by arrays and TradingView's object caps. "Keep historical drawings" does not mean unlimited history.
10. Normalize XAUUSD aliases and broker contract metadata before comparing feeds or costs.

These findings are observations only. The baseline remains unchanged.
